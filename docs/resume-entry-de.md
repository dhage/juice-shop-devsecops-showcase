# DevSecOps Showcase Plattform

Konzeption und Implementierung einer vollständigen DevSecOps-Referenzplattform auf Basis von OWASP Juice Shop.

Technologien:

Docker, GitHub Actions, Semgrep, OWASP Dependency Check, Trivy, Checkov, Kubernetes und Terraform.

Erreichte Ergebnisse:

- Implementierung automatisierter SAST-, SCA- und Container-Security-Scans
- Integration von Kubernetes Security Validation
- Aufbau von Security Gates innerhalb der CI/CD-Pipeline
- Durchführung von Threat Modeling und Risikoanalysen
- Dokumentation eines Secure-SDLC-Prozesses
- Erstellung von Architecture Decision Records (ADR)
