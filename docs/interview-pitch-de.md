Ich habe eine vollständige DevSecOps-Referenzplattform auf Basis von OWASP Juice Shop aufgebaut.

Dabei habe ich verschiedene Sicherheitskontrollen direkt in die CI/CD-Pipeline integriert, darunter Semgrep für SAST, OWASP Dependency Check für Dependency Scanning, Trivy für Container Security sowie Checkov für Kubernetes Security.

Zusätzlich wurden Security Gates, Threat Modeling, Risikoanalysen und Secure-SDLC-Dokumentation umgesetzt.

Das Ziel war, den gesamten Software Delivery Lifecycle unter Security-Aspekten abzubilden und moderne DevSecOps-Praktiken praktisch umzusetzen.
