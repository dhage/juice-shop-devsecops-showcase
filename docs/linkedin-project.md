Recently I completed a hands-on DevSecOps showcase project using OWASP Juice Shop.

The project demonstrates how security can be integrated throughout the software delivery lifecycle by combining:

✅ GitHub Actions

✅ Semgrep (SAST)

✅ OWASP Dependency Check (SCA)

✅ Trivy Container Security

✅ Checkov Kubernetes Security

✅ Terraform

✅ Kubernetes

✅ Security Gates

✅ Threat Modeling

✅ Secure SDLC Practices

The goal was not only to automate deployment but also to shift security controls left and enforce security validation throughout the CI/CD pipeline.
