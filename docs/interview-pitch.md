I built an end-to-end DevSecOps showcase using OWASP Juice Shop.

The project integrates multiple security controls directly into the CI/CD pipeline including Semgrep, Trivy, OWASP Dependency Check and Checkov.

I also implemented security governance using Security Gates, documented a Secure SDLC process, performed threat modeling and created architecture decision records.

The goal was to demonstrate how security can be integrated across the complete software delivery lifecycle from development to deployment.
