Vor Kurzem habe ich ein praxisorientiertes DevSecOps-Showcase-Projekt auf Basis von OWASP Juice Shop umgesetzt.

Ziel war es, Security-Kontrollen über den gesamten Software Delivery Lifecycle hinweg zu integrieren und einen modernen DevSecOps-Ansatz abzubilden.

Zum Einsatz kamen unter anderem:

✅ GitHub Actions

✅ Semgrep (SAST)

✅ OWASP Dependency Check (SCA)

✅ Trivy Container Security

✅ Checkov Kubernetes Security

✅ Terraform

✅ Kubernetes

✅ Security Gates

✅ Threat Modeling

✅ Secure SDLC

Der Schwerpunkt lag darauf, Security möglichst früh in den Entwicklungsprozess zu integrieren (Shift-Left Security) und automatisierte Sicherheitsprüfungen direkt innerhalb der CI/CD-Pipeline umzusetzen.
