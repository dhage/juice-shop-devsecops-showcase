# DevSecOps Showcase – Zusammenfassung

Dieses Projekt demonstriert die praktische Umsetzung eines End-to-End-DevSecOps-Ansatzes auf Basis von OWASP Juice Shop.

Implementierte Komponenten:

- CI/CD mit GitHub Actions
- Semgrep für Static Application Security Testing (SAST)
- OWASP Dependency Check für Software Composition Analysis (SCA)
- Trivy für Container Security
- Checkov für Kubernetes Security Validation
- Security Gates
- Terraform als Infrastructure as Code
- Kubernetes Deployment Manifeste
- Threat Modeling
- Risikoanalyse
- Secure SDLC Dokumentation
- Architecture Decision Records (ADR)

Das Projekt zeigt die Integration von Sicherheitskontrollen über den gesamten Software-Lebenszyklus hinweg – von der Entwicklung bis zur Bereitstellung.
