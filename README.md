# DevSecOps Showcase with OWASP Juice Shop

## Overview

This project demonstrates the implementation of a modern DevSecOps pipeline using OWASP Juice Shop.

The goal is to integrate security controls across the entire software delivery lifecycle.

## Technologies

- OWASP Juice Shop
- Docker
- GitHub Actions
- Semgrep
- Trivy
- OWASP Dependency Check
- Kubernetes
- Terraform
- Prometheus
- Grafana

## Security Controls

### SAST
- Semgrep

### Dependency Scanning
- OWASP Dependency Check

### Container Security
- Trivy

### CI/CD
- GitHub Actions

### Infrastructure as Code
- Terraform

### Container Orchestration
- Kubernetes

## Pipeline Vision
